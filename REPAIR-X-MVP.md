# REPAIR-X MVP Plan

## Goal
Demonstrate one complete, real software-maintenance loop.

## Workflow
1. Bug report
2. Repository analysis
3. Bug reproduction
4. Root-cause analysis
5. Patch proposal
6. Human approval
7. Patch application
8. Regression test generation/execution
9. Impact analysis
10. Proof-of-Fix

## Verification rule
A repair is VERIFIED only when the actual relevant tests pass after the approved patch is applied and required evidence is present.

## Development phases
- Phase 1: foundation
- Phase 2: repository analysis
- Phase 3: reproduction
- Phase 4: repair proposal/approval
- Phase 5: patch application
- Phase 6: test runner
- Phase 7: impact analysis
- Phase 8: Proof-of-Fix
- Phase 9: dashboard
