# REPAIR-X Architecture

```text
Bug Report
   ↓
Repository Analyzer
   ↓
Bug Reproduction
   ↓
Root Cause Analysis
   ↓
Fix Proposal
   ↓
Human Approval
   ↓
Patch Application
   ↓
Regression Tests
   ↓
Impact Analysis
   ↓
Proof-of-Fix
```

## Components
1. Bug Intake
2. Repository Analyzer
3. Reproduction Runner
4. Root Cause Service
5. Patch Proposal/Approval
6. Patch Application
7. Test Runner
8. Impact Analyzer
9. Proof-of-Fix Engine
10. React Dashboard
